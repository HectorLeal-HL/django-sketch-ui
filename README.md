# Django Sketch UI

Un tema moderno y personalizable para interfaces de Django.

## Instalación

Instala el paquete usando pip:

```bash
pip install django-sketch-ui
```

## Configuración

Para que se apliquen los estilos se tiene que agregar `django_sketch_ui` al principio de la lista `INSTALLED_APPS` que se encuentra en `settings.py` en la base de tu proyecto.

```bash
INSTALLED_APPS = [
    "django_sketch_ui",
    ...
]
```

## Version Estable

Por errores de subir el tema a Pypi, la version 1.0.0 es la version estable, ya que esta cargada correctamente la app.
